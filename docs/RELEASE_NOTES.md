設定隔離、驗證強化與可選串流推論。

- config.json 不再納入版控或發布包；首次自範本建立，已有設定不覆蓋。
- 舊專案狀態先備份再遷移至 .pcb_state.json；既有狀態優先，設定／狀態原子寫入。
- 本地模式可選 SSE 預覽；區分連線、閒置讀取與每次 HTTP 請求總逾時。須 stop＋[DONE] 才成功；斷線、截斷、逾時或取消不保存為成功結果。
- 幾何規則在啟動 KiCad 前做 Schema 預檢；ERC／DRC 報告檢查必要結構，格式錯誤不當作零違規。
- 新增 PCB 解析樣本與雙頁原理圖／未接腳位的真實 KiCad 整合測試；76 項本機測試。

舊 Git clone 更新前請先備份個人 config.json；新 ZIP 可放回舊設定，由程式自動遷移。複雜板框與完整工程放行仍須獨立確認。GPL-3.0-only 授權不變。
